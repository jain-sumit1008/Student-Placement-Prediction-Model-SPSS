# 🎓 Student Placement Prediction System using IBM SPSS Modeler

An end-to-end machine learning project developed using **IBM SPSS Modeler** to predict student placement outcomes using academic performance, technical skills, and internship experience.

---

# 📌 About the Project

This project was developed as part of our academic assignment under the guidance of our faculty mentor.  
Our team designed and implemented the complete prediction workflow within a few hours using IBM SPSS Modeler and successfully pushed the project to GitHub for submission.

The project demonstrates how machine learning can be used to automate placement prediction using student-related data.

- 📊 Student Placement Prediction

- ⚡ Fast End-to-End Workflow

# 🧠 Problem Statement

Educational institutions often face difficulty in analyzing which students are likely to get placed based on their academic and technical performance.

Manual analysis can be:
- Time-consuming
- Inconsistent
- Error-prone

This project aims to automate placement prediction using machine learning techniques in IBM SPSS Modeler.

---

# 🎯 Objectives

- Predict student placement status
- Reduce manual analysis
- Improve prediction efficiency
- Identify key placement factors
- Build an interpretable ML model

# 🌳 Machine Learning Model

The C&R Tree model was used for classification of placement status.

### Advantages:
- Easy to understand

- Good interpretability
- Suitable for classification tasks
